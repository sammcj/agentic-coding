# Examples

## Altitude - Quarterly Business Review

**Surface prompt:** "Make me a QBR deck from these numbers."

**Elevated sequence:**

1. "Here is every data source I can get. Tell me what changed this quarter, why, and what we should do about it."
2. "Work out which three decisions are most urgent. Start drafting for/against arguments for each."
3. "The review exists so leadership catches problems early and moves money and people. Design a better way to do that than a quarterly deck. Show from our own history that it would have caught things sooner, and propose running it beside the current one for a quarter."

## Depth - Churn Analysis

**Surface prompt:** "Analyse why users churn. I think onboarding is the problem."

**Depth rewrite:** run the Depth meta-prompt from SKILL.md, then challenge the hypothesis: "We believe churn is an onboarding problem. Try to reproduce that from the raw data."

Expected outcome includes:
- Raw event logs or database queries
- Statistical models or survival analysis
- Simulation that reproduces the last year
- Earliest unknown predictive signal tested on held-out data
- External validation metric or tool

## Range - Homepage / Creative Work

**Surface prompt:** "Redesign my personal homepage."

**Range approach:**

1. Replace the noun: "Create an experience that makes a busy visitor immediately understand what I do, trust me, and take one concrete action, in under 30 seconds."
2. Assemble the crew: "Apply what an editor, a narrative journalist and a motion designer each do to this page, with the tools each would use, including ones from outside web design such as Blender for a 3D environment. Then red-team it: find the reasons a visitor leaves."
