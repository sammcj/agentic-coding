# OpenSpeccer demo - narration script

Timed to `openspeccer.mp4` (1:26). Word counts sit under about 2.2 words per second so there's room to breathe.

## 1. Dashboard (0:00 - 0:12)

_On screen: stat tiles, the kanban board, then specs in flight._

This is OpenSpeccer, a read-only dashboard for OpenSpec projects. Active changes sit on a board by stage, with their task progress and the specs they touch.

## 2. Change (0:12 - 0:25)

_On screen: open suggestion-quality, scroll the tasks, switch to Specs then Proposal._

Open a change and each artifact gets its own tab: the tasks with progress per section, the delta specs, the design and the proposal.

## 3. Specs (0:25 - 0:37)

_On screen: filter the tree, open app-shell, scroll, then the History tab._

Specs are a filterable tree. Each one is broken into requirements and scenarios, and History lists every change that's touched it.

## 4. Timeline (0:37 - 0:48)

_On screen: hover across the open changes chart, then open the Export menu._

The timeline shows how fast changes are opening and closing, with a projected clear date. Any page can be exported as Markdown or HTML.

## 5. Schemas (0:48 - 0:55)

_On screen: the spec-driven workflow graph, click the design step._

Schemas are drawn as a workflow, so you can see what each artifact depends on.

## 6. Agents (0:55 - 1:01)

_On screen: the agent cards._

Agents shows which coding agents have OpenSpec skills installed.

## 7. Commands (1:01 - 1:13)

_On screen: scroll the reference, filter for archive, copy `openspec archive`._

Commands is a reference built from your installed OpenSpec CLI. Filter it, and click any command to copy it.

## 8. Live (1:13 - 1:26)

_On screen: task 13.6 in mvp-a ticks itself, then the dashboard shows 72 of 74._

And it's live. When an agent ticks off a task, the page updates by itself. It runs locally as an agent skill, with nothing to install.
